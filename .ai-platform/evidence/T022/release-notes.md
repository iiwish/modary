# v0.1.0-alpha.1 Rejected

Do not use this tag. Install `v0.1.0-alpha.2` instead.

The immutable tag passed Linux quality, Darwin arm64 native validation, tag
preflight, and normal Go module resolution. Its copied-out remote consumer then
exposed checkout-only example assertions that did not recognize removal of the
local source replacement. The release gate failed, so this version is not
supported.

The tag had already been cached by the public Go proxy and is retained unchanged
for provenance. No binaries or application artifacts are attached.

Report vulnerabilities privately at
https://github.com/iiwish/modary/security/advisories/new.
