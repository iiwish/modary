# v0.3.0-alpha.1 Release Notes Record

- Name: Modary v0.3.0-alpha.1
- Type: GitHub prerelease
- Published: 2026-08-04T09:31:29Z
- URL: https://github.com/iiwish/modary/releases/tag/v0.3.0-alpha.1

The release presents the Production Foundation as a database-free Core with
explicit PostgreSQL, Governed PostgreSQL, OIDC, OpenTelemetry, React Admin,
deployment, and operations selections. It calls out the breaking principal,
identity-store, process-command, and health-probe contracts, links the v0.2 to
v0.3 upgrade guide, and states the process-local OIDC ceremony and PostgreSQL
support boundaries.
