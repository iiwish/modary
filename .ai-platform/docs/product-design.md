# Current Product Contract

- Version: 2.0
- Status: Confirmed
- Last updated: 2026-07-31
- Source: explicit user approval of the framework-decoupling analysis

Modary is a Go-first modular application kernel, SDK, and build tool. Independent
applications compose public Module packages and execute typed Actions through a
single governed Runtime across human and Agent channels. Consumer applications
own their domain, branding, migrations, policy, bootstrap data, UI, and release
artifacts.

The authoritative F0 product and acceptance contract is
`.ai-platform/specs/002-framework-decoupling/spec.md`.

Technical F0 acceptance proves local source consumption; it is not a remote
distribution. The current framework has no published version tag and no
owner-selected redistribution license, so the source tree grants no public
redistribution right by implication.
