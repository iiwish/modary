# PostgreSQL Alpha 3 Publication Requirements Checklist

- [x] Version is explicit, semantic, new, and immutable.
- [x] Accepted source and release scope are identified.
- [x] Candidate and tag validation commands are executable.
- [x] Main CI, tag CI, module resolution, and remote consumption are required.
- [x] Every irreversible transition has a preceding stop gate.
- [x] Earlier public tags are protected from movement or reuse.
- [x] License, security channel, compatibility, and upgrade boundaries are stated.
- [x] Final evidence and claim-review requirements are explicit.
- [x] Downstream consumer products and their artifacts are outside the release object.
